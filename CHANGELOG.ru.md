# История изменений

[English](CHANGELOG.md) · **Русский**

Новые версии сверху. Описание релиза на GitHub и changelog на CurseForge берутся из английской версии, [CHANGELOG.md](CHANGELOG.md).

## 1.0.3
- На выделенном сервере сообщение о весе над хотбаром больше не появляется раз в 10 секунд рядом с полосой: сервер выполнял клиентский код этого сообщения без клиентского конфига, который его отключает.

## 1.0.2
- Опция `enable_food_exhaustion` работает как описано: груз сверх порога Exhausted ускоряет голод, на максимальном весе вдвое против пассивного голода TFC. Раньше опция ничего не делала.

## 1.0.1
- Игроки в creative и spectator больше не видят сообщение о весе над хотбаром: вес на них не действует.
- Закрытие мира больше не пишет ошибку в лог: конфиг не читает значения во время выгрузки.

## 1.0.0
- Первый выпуск. Добавляет расчёт веса для всех слотов игрока и Curios и для всех предметов.
- Есть опции конфига, отключающие мод целиком либо отдельно дебаффы и расход сытости.
